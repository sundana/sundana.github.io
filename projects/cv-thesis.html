Real-Time Object Detection for Autonomous Systems

Master's Thesis · 2025

Overview

This thesis investigates real-time object detection architectures for resource-constrained autonomous systems, focusing on the trade-off between detection accuracy and inference latency. The work introduces a novel lightweight backbone network that achieves state-of-the-art performance on embedded GPU hardware while maintaining real-time throughput.

Motivation

Autonomous systems operating at the edge face severe computational constraints. Traditional object detection models like YOLO and Faster R-CNN excel on server-grade hardware but struggle to maintain real-time inference on embedded devices. This work addresses the gap by designing an architecture co-optimized for both accuracy and hardware efficiency.

Technical Approach

Architecture Design

  • Custom lightweight backbone based on depthwise separable convolutions and inverted residual blocks
  • Feature Pyramid Network (FPN) with cross-scale connections for multi-resolution detection
  • Anchor-free detection head to reduce computational overhead from bounding box regression
  • Knowledge distillation from a larger teacher model (YOLOv8-X) during training

Training Pipeline

  • Dataset: COCO 2017 + custom annotated urban driving dataset (15K images)
  • Data augmentation: Mosaic, MixUp, random affine transforms, HSV jitter
  • Loss function: Combination of Varifocal Loss (classification) and CIoU Loss (regression)
  • Optimizer: AdamW with cosine annealing and warmup
  • Mixed precision training on 2× NVIDIA A100 GPUs

Deployment Optimization

  • INT8 quantization via TensorRT for NVIDIA Jetson Orin
  • Operator fusion and graph optimization to reduce kernel launch overhead
  • Pruned 40% of channels with minimal accuracy degradation using L1-norm channel pruning

Results

Model mAP@0.5 mAP@0.5:0.95 Latency (ms) Params (M)
YOLOv8-Nano 37.3 21.8 12.4 3.2
MobileNetV3-SSDLite 32.1 18.6 15.8 4.9
Ours (FP32) 41.2 25.1 14.1 3.8
Ours (INT8) 40.6 24.4 7.8 3.8

The proposed architecture achieves a 10.4% improvement in mAP@0.5 over YOLOv8-Nano at comparable latency, and the INT8-quantized variant delivers 7.8ms inference on Jetson Orin — well within the 30ms real-time budget for autonomous driving.

Key Contributions

  1. A novel lightweight backbone optimized through Neural Architecture Search (NAS) with hardware-aware constraints
  2. Empirical analysis of knowledge distillation strategies for compact object detectors
  3. Open-source deployment pipeline for ONNX → TensorRT with quantization-aware training
  4. Comprehensive ablation study on the impact of data augmentation on small object detection
